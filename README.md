# 🐱 Dancing Cat — Мобильная ритм-игра

Веб-игра, в которой нужно тапать в ритм музыки, чтобы кот танцевал.
Никаких зависимостей, никаких сборщиков — чистый HTML/CSS/JS.

## 🎮 Геймплей
- В центре экрана — кот, который танцует и меняет позы
- Из-за краёв экрана «вылетают» кольца-ноты
- Когда кольцо достигает кота — тапни по экрану (или нажми пробел на ПК)
- **PERFECT** — точно в бит, **GOOD** — близко, **MISS** — промах
- Комбо и множитель очков (×2 / ×3 / ×4)

## 🚀 Локальный запуск

Игра требует запуска через локальный HTTP-сервер (не `file://`),
чтобы Web Audio API работал.

```bash
cd C:\Users\Vasilii\IdeaProjects\dancer
python -m http.server 8000
```

Открой `http://localhost:8000` в браузере.

## 📱 Запуск на телефоне (та же Wi-Fi)

1. Узнай IP ПК: `ipconfig` → IPv4-адрес (например, `192.168.1.42`)
2. Убедись, что файрвол Windows разрешает входящие на порт 8000
3. На телефоне открой `http://192.168.1.42:8000`

## ☁️ Деплой онлайн (бесплатно)

### Вариант 1: Netlify Drop (самый простой — 1 минута)
1. Открой https://app.netlify.com/drop
2. Перетащи папку `dancer/` (всю, кроме `.idea/`) в окно браузера
3. Получишь ссылку вида `https://random-name.netlify.app`
4. Готово! Открывай с телефона

### Вариант 2: GitHub Pages
1. Создай репозиторий на github.com
2. Залей файлы: `git init && git add . && git commit -m "init" && git push`
3. Settings → Pages → Source: `main` branch, папка `/` (или `/docs`)
4. Ссылка: `https://<user>.github.io/<repo>/`

### Вариант 3: Vercel
1. https://vercel.com → Sign up with GitHub
2. Import Project → выбери репозиторий
3. Deploy → готово

## 📁 Структура

```
dancer/
├── index.html          # разметка экранов
├── style.css           # мобильный first, неон, адаптивность
├── js/
│   ├── audio.js        # загрузка/воспроизведение MP3
│   ├── audio-beats.js  # анализ ритма трека
│   ├── cat.js          # позы, ноги, руки
│   ├── cat-draw.js     # тело, аура, хвост
│   ├── cat-head.js     # морда, глаза, уши
│   ├── notes.js        # кольца-ноты, проверка попаданий
│   ├── game.js         # состояние, экраны, ввод
│   └── game-loop.js    # render-цикл
└── assets/
    └── song.mp3        # трек
```

## 🎵 Замена трека
Замени `assets/song.mp3` на любой другой MP3. Алгоритм анализа
ритма автоматически подстроит ноты под новый трек при загрузке.
Для очень тихих или сложных треков может понадобиться ручная настройка
порога в `js/audio-beats.js` (параметр `1.3` в строке `threshold`).
